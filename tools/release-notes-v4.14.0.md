## WallDesk v4.14.0

设置页换子页不再「啪」地整块替换，改成一段短淡入。

### 新增

- **子页切换缓动**：点设置左侧的「壁纸 / 播放 / 场景 / 外观与效果 / 高级」换页时，
  新页内容在 160ms 内从透明过渡到不透明。曲线只做减速（`OutCubic`），不回弹过冲。
- **配置项 `uiPageFadeMs`**：默认 160，写 `0` 关闭，上限 1000。这一版先只走配置文件。

### 说明

- 不透明度效果只在动画期间挂在控件上，结束立刻摘除。常驻效果会让整棵子树每帧走离屏绘制，
  长期挂着是净亏——这一点比动画本身更影响资源占用。
- 系统里关掉「在 Windows 中显示动画」时自动不做过渡（读 `SPI_GETCLIENTAREAANIMATION`）。
- 只在设置页真正显示在屏幕上时才演：启动时恢复上次子页、程序化改页码都保持瞬时切换。
- **左侧主导航（壁纸库 / 设置 / 多屏）没有加整页过渡**：整页挂不透明度效果会把含缩略图
  网格的整页每帧重绘成位图，低端机上是倒退。要做应该走「抓快照做交叉淡出」。

### 安装

- 安装包：`WallDesk-4.14.0-setup.exe`（安装到用户目录，无需管理员权限）
- 绿色版：`WallDesk-4.14.0-win64.zip`，解压即用；便携模式在 exe 同目录放空的 `portable.ini`。
