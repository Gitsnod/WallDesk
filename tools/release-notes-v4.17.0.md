# WallDesk v4.17.0 — Material 大圆角与交互动效

按钮、下拉、复选框、滑块、菜单全部有了过渡动画；底部状态胶囊并进状态栏，
鼠标悬停才展开诊断详情。

## 新增

- **按钮交互动效**：悬停叠一层 8% 主色、按压叠 10% 并让内容下沉 1px、
  触点 ripple 从按下的位置扩散 400ms（按住不足 225ms 不触发）、键盘焦点环自绘。
- **下拉框**：弹层展开 + 淡入 + 箭头旋转，选中后 200ms 内收起，不再瞬开瞬关。
- **复选框**：勾分两段描出，底色与边框从卡片色插值到主色，约 120ms；
  单选按钮同步换成 M3 的「主色环 + 中心圆点」。
- **滑块**：handle 悬停放大 1.4px、按压再放大 0.9px，带一圈主色光晕。
- **菜单**：弹出时 200ms 淡入。
- **场景淡入**：壁纸库 / 设置 / 多屏 之间切换整页从背景色淡入 200ms；
  壁纸库在空状态与列表之间切换淡入 160ms。
- **底部状态胶囊**：帧率与内存胶囊嵌进状态栏最右侧，配色跟随主题。鼠标在胶囊上
  停留 200ms 后，上方弹出详情浮层：解码档位、下发参数、媒体与分辨率、实时帧率、
  缩略图缓存、内存（含峰值）、运行时长。移开即收起，鼠标扫过不弹。

## 变更

- 控件高度按内容收紧并与同类齐平：按钮、下拉、输入框统一 30px 级。
  上一版试过按触摸口径给到 40px 级，桌面场景下显得臃肿，已回调。
- 设置页子导航与左侧主导航拉开层级：子导航改透明底、选中只变字色，
  不再出现两个同为蓝底的「选中项」并排。

## 修复

- **主按钮禁用态变直角方块**：「应用选中」在没有选中项时是禁用态，走的是
  `QPushButton#primary:disabled` 这条更具体的选择器，而它没有声明 `border-radius`，
  Qt 用伪类规则整体替换基础规则后回落到直角。禁用态改为自绘后形状统一。
- **单选按钮选中态同样的方角**：`QRadioButton::indicator:checked` 缺 `border-radius`，
  同一根因。伪类规则必须把 `border-radius` 逐条重复声明。
- **按钮首次悬停瞬跳**：动画起点用 `underMouse()` 反推，Enter 事件到达时它已为真，
  起点等于终点。改为自持强度值。
- **状态胶囊遮挡内容**：原先浮在内容右下角，深色底色在浅色主题下像一块贴片，
  且会盖住列表末行与滚动条。

## 实现说明（为什么整页淡入不用 QGraphicsOpacityEffect）

给整页设 `QGraphicsOpacityEffect` 做 opacity 0→1，本机实测动画期间窗口不逐帧重绘：
屏幕停在上一个页面的像素，动画结束瞬间才跳成新页，等于没有动画（800ms 时长下同样
可复现）。改用自绘遮罩 `FadeOverlay`——在目标区域上盖一层背景色，alpha 1→0 用
`QVariantAnimation` 驱动，每帧 `update()`，渲染路径和 ripple 一致，逐帧可见。
设置子页的淡入仍用 effect：那是对页内 GroupBox 逐个做的，实测有中间态。
