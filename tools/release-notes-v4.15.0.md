## WallDesk v4.15.0

给图片套画面效果时，界面不再卡住。

### 变更

- **画面效果移到后台线程计算**：读图、逐像素处理（亮度 / 对比度 / 饱和度 / 灰度 / 模糊 / 暗角）
  以及写缓存副本，全部从 UI 线程搬到专用工作线程；UI 线程只保留最后一步「交给系统」。
  实测 4000×3000 的图配模糊 15、暗角 80：界面最长卡顿 **2.29 秒 → 0.33 秒**。
- **连点不串位**：快速连点两张图时，先点那张若算完时已经过期会被丢弃，
  不会出现「后点的先生效、先点的又盖回去」。
- **多屏同批处理**：给多块屏幕分别设壁纸时，先把所有特效副本在后台算完，再一次性逐屏下发，
  不再一块屏卡一次。

### 诊断

- 日志新增一行：`画面效果已生成：<文件>（2175 ms，执行线程 0x6840 / UI 线程 0x46e8）`。
  耗时与「到底在哪个线程算的」都能直接看到。

### 已知

- **超大图的剩余耗时在系统接口上**：同一张 4000×3000 图即使不加任何特效，点击到壁纸生效
  仍需约 5.8 秒——`SPI_SETDESKWALLPAPER` 内部会重新编码壁纸，这段在本次改动之外。
  后续方向是先把图缩放到虚拟桌面分辨率再下发。普通尺寸（1080p / 4K 照片）没有这个量级的开销。

### 安装

- 安装包：`WallDesk-4.15.0-setup.exe`（安装到用户目录，无需管理员权限）
- 绿色版：`WallDesk-4.15.0-win64.zip`，解压即用；便携模式在 exe 同目录放空的 `portable.ini`。
