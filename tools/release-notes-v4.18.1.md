# WallDesk v4.18.1

这一版全部是「看得出来但说不上哪里怪」的问题，逐个拍照量出来的。

## 下拉框

原来它和文本框是同一副长相：白底、1px 描边、右边一小截空白。为了让它像下拉框，
上一版补了箭头，但底色没变，还是像个输入框。

现在换成 Material 3 的 filled select：

- 浅灰填充、无描边，悬停才出细边，展开或键盘聚焦时描边转主色
- 箭头在展开时旋转 180°，收起再转回来
- 白底描边的文本框、微调框保持原样 —— 底色一深一浅，哪个能打字、哪个要点开选，一眼分得清

弹出列表也一起重做了。它是个独立原生窗口，Qt 内部自己画方角菜单面板，样式表改不动它，
所以这一版直接接管绘制：圆角卡片 + 1px 描边 + 窗口 mask 切角，条目高 26px、宽度和下拉框对齐，
并去掉了列表拿到焦点时那一圈灰框。

顺带修了落点。Qt 默认的弹出位置实测会压住下拉框上半截，现在改成自己算：下方放得下就贴在下沿，
放不下翻到上方，左右夹在屏幕可用区内。

## 「更多」

它是带菜单的按钮，但箭头挂在最右侧的留白里，形状和旁边的下拉框一模一样。

现在箭头紧跟文字 6px，「文字 + 箭头」作为一个整体居中，白底 + 描边与「下一张」「暂停视频」同一套。

## 复选框

两个问题：

- **点一下像选中了整行**：焦点环原来沿着整个控件矩形画，把文字一起圈进去了。现在只圈 18px 方块本身
- **浅色主题下几乎看不见**：未选中态原来是 1px 近白色描边。改成 2px 中性灰，勾选后填充主色、
  白勾笔画从 2.0 收到 1.8（18px 方块里 2px 会糊成一坨），悬停时描边转主色并铺一层极浅的主色底

## 滑块

控件高度只有 17px，而悬停光晕要画 29px 的直径——上下被裁平，左端 0% 位置还被切掉一块，
鼠标一放上去就是个方块贴纸。

控件最小高度提到 24px，左右留白 12px（原来按 handle 半径算的 9px，不够），光晕半径收到 11.8px。
现在四个方向都在框内。
