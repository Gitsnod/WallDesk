# WallDesk v4.16.0 — 空闲暂停

没人碰键盘鼠标时，视频壁纸自己停下来省电；一有输入马上续播。

## 新增

- **空闲暂停**：整个系统没有鼠标移动、没有按键达到设定时长后，暂停视频壁纸，
  画面停在当前帧。任何键鼠输入后半秒内自动续播，不黑屏、不重载。
  默认关闭，在「设置 → 省电」勾选「空闲时暂停」，阈值 1–120 分钟（默认 5 分钟）。
- 暂停原因标签新增「空闲 N 分钟」，与手动 / 锁屏 / 电池 / 全屏 / 远程会话 /
  逐应用规则并列，随时可查当前卡在哪一条原因上。

## 实现说明（为什么是整播暂停而不是 15 fps）

竞品调研报告里的原始建议是「空闲 N 秒后降到 15 fps」。实施时确认：libVLC 公共 API
不支持给**已起播**的播放器增删视频滤镜，`fps` 滤镜只能在起播前挂载，切换意味着
停播重加、恢复时有一次可见卡顿；自定义 vout 或裸帧回调自渲染等于自建渲染链路，
丢失 GPU 加速且 DRM 内容直接失效。因此改为整播暂停——它是本项目既有聚合暂停架构
内的自然扩展，空闲时解码完全停止（比 15 fps 更省），恢复时无重载。

## 其他

- 空闲判定只看系统级键鼠输入（`GetLastInputInfo`，500 ms 轮询）。原建议中的
  「无音频」「无焦点变化」对壁纸场景不适用（壁纸默认静音输出、从不获得焦点），未实现。

## 校验

- `tools/check_sources.py`：括号平衡、符号齐备、绑定完整、枚举全覆盖，通过。
- 实测完整循环（阈值设为 1 分钟，日志为证）：
  - `18:40:06 空闲暂停：已 943 秒无键鼠输入`（启动即触发）
  - `18:40:56 检测到键鼠输入，取消空闲暂停`（合成输入后约 1 秒内）
  - `18:41:56 空闲暂停：已 60 秒无键鼠输入`（恰好等于阈值，精度符合预期）
  - `18:43:29 空闲暂停：已 60 秒无键鼠输入`（再次精确触发，循环可重复）
- 界面 A/B：暂停态按钮为「继续视频」、状态栏「视频壁纸已暂停（有输入立即恢复）」；
  播放态按钮为「暂停视频」、状态栏「视频壁纸继续播放」。
