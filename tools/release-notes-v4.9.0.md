## 4.9.0 - 2026-10-21

这一版不加新格式，专治「资源怎么用」：暂停不再互相打架，可以按程序决定壁纸去留，
也能在某个程序进入前台时自动换一套桌面。

变更类型按 [Keep a Changelog 1.0.0](https://keepachangelog.com/zh-CN/1.0.0/) 分组，
完整历史见仓库根目录的 `CHANGELOG.md`。

### 修复（Fixed）

- **暂停互相撤销**：以前锁屏 / 电池 / 全屏三路各改各的状态，退出全屏会把「电池供电」
  仍需要的那次暂停一并解掉。现在所有原因（手动 / 锁屏 / 电池 / 全屏 / 远程会话 / 逐应用规则）
  统一合成，任一成立就保持暂停；设置页会显示当前生效的原因。

### 新增（Added）

- **逐应用规则**：设置 → 播放 → 资源控制。按前台窗口所属进程决定壁纸去留——
  「暂停」= 该程序在前台时停掉壁纸；「忽略」= 该程序全屏时继续播放（压住全屏暂停）。
  同一进程只保留一条规则，双击可切换动作。
- **触发规则**：设置 → 场景 → 触发规则。指定程序进入前台时自动套用某个场景预设，
  切到游戏自动换成另一套桌面。切到其它程序不会自动切回，避免来回抢壁纸。
- **远程桌面暂停**：被远程控制时暂停壁纸以省 GPU 与上行带宽，会话断开后自动恢复；默认开启。
- **解码档位「省电（限制解码线程）」**：硬件解码 + `--avcodec-threads=2` + 允许丢帧，
  笔记本与小主机的负载比「自动」更低。

### 变更（Changed）

- 日志会记录所选解码档位与其实际下发的 libVLC 参数，便于确认硬件解码是否真的生效。
- 规则类配置（逐应用规则 / 触发规则）改存「换行分隔的普通字符串」，人可读、可手改；
  启动日志新增一行配置载入摘要。
- 设置页底部留白加大，内容贴边时不再显得拥挤。

### 兼容性与注意

- **配置格式兼容**：新增的键在旧配置里不存在时按默认值处理，不需要迁移，可直接覆盖安装。
- 逐应用规则与触发规则**默认关闭**；远程桌面暂停**默认开启**。
- 便携模式的配置在 `程序目录\data\WallDesk\WallDesk.ini`，安装模式在
  `HKCU\Software\WallDesk\WallDesk`——手改规则时别改错位置。
- 本版**未包含**「图库卡片悬停动态预览」，它需要额外的解码实例，放在下一版评估。

### 安装说明

- `WallDesk-4.9.0-setup.exe` — 安装程序，装到 `%LOCALAPPDATA%\Programs\WallDesk`，无需管理员权限。
- `WallDesk-4.9.0-win64.zip` — 绿色版，解压即用。

视频引擎 libVLC 3.0.x 已内嵌，无需单独安装 VLC。
各文件校验值见包内 `SHA256SUMS.txt`。
