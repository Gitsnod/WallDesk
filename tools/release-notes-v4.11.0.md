## WallDesk v4.11.0

这一版不加播放能力，补的是「状态看得见」和「第一次打开不像坏了一样」。

### 新增

- **右下角状态胶囊**：常驻显示 `解码档位 · 分辨率 · 实时帧率 · 进程内存`。
  点一下展开详情：下发给 libVLC 的档位参数、当前媒体文件、缩略图缓存占用、峰值内存、运行时长。
  以前想确认「硬件解码到底有没有生效」得翻日志，现在看一眼右下角就知道。
- **空库三步引导**：第一次打开时列出「添加文件 → 选填充方式 → 双击应用」。
- **一键示例壁纸**：空库页的「没有素材？生成一张示例壁纸」会现场画一张 1920×1080 渐变图，
  写进数据目录并加入壁纸库，双击即可应用成桌面。

### 变更

- 帧率来自 libVLC 的 `get_fps`，作为**可选符号**绑定：老版本运行库没有它时显示 `—`，不影响播放。
- 读取进程内存需要链接系统库 `psapi`（Windows 自带，不增加发布包体积）。

### 说明

- 状态胶囊 2 秒刷新一次；展开时的缩略图缓存统计只在展开那一刻算一次。
- 这一版没有改播放、暂停和规则相关逻辑，升级后原有配置与预设不受影响。

### 安装

- 安装包：`WallDesk-4.11.0-setup.exe`（安装到用户目录，无需管理员权限）
- 绿色版：`WallDesk-4.11.0-win64.zip`，解压后直接运行 `WallDesk.exe`；
  便携模式在 exe 同目录放一个空的 `portable.ini`（或加 `--portable`），配置写在程序目录 `data\` 下。

完整变更记录见 [CHANGELOG.md](https://github.com/Gitsnod/WallDesk/blob/main/CHANGELOG.md)。
