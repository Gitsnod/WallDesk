## WallDesk v4.12.0

这一版把「往里加东西」做顺了：不用点菜单选文件，直接从资源管理器拖进来。

### 新增

- **拖拽导入**：把图片 / 视频文件，或整个文件夹，拖到 WallDesk 窗口上。拖拽期间窗口中间会显示
  蓝色虚线框和「松开鼠标，添加到壁纸库」，松手即入库。
  - 文件夹递归扫描（上限 4000 个文件），子目录里的也会加进来。
  - 支持 `jpg / jpeg / png / bmp / webp / gif` 与 `mp4 / mkv / webm / avi / mov / wmv / flv`，
    其它扩展名跳过。
  - 已在库里的路径不会重复添加，状态栏会写明「已加入 N 个文件，跳过 M 个」。
- **命令行导入**：`WallDesk.exe --import <文件或目录>`，导入后立即退出。
  适合做成资源管理器「发送到」的快捷方式，或脚本批量投喂。

### 变更

- 「添加图片 / 添加视频」对话框的扩展名过滤改为与拖拽共用同一份列表，
  以后加格式只改一处，不会再出现「拖拽能收、对话框看不见」的错位。

### 说明

- 拖拽与命令行走的是同一个 `importPaths()`，去重、分类、提示与日志口径一致
  （日志形如 `导入完成：新增 2 个，跳过 1 个`）。
- 只接受本机文件路径；从浏览器直接拖图片（临时 URL）不会入库，请先保存到本地。

### 安装

- 安装包：`WallDesk-4.12.0-setup.exe`（安装到用户目录，无需管理员权限）
- 绿色版：`WallDesk-4.12.0-win64.zip`，解压即用；便携模式在 exe 同目录放空的 `portable.ini`。
