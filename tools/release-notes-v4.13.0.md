## WallDesk v4.13.0

只改观感：缩略图不再「啪」地跳出来。

### 新增

- **缩略图淡入**：真实缩略图第一次绘制时，用 180ms 从透明过渡到完全不透明。
  占位图**不参与**淡入——否则会先淡入一个假图、再淡入真图，两次闪动比硬切换更难看。
- **配置项 `uiFadeMs`**：默认 180，写 `0` 关闭，上限 1000。这一版先只走配置文件，
  设置界面的开关放到下一轮界面批次。

### 说明

- 淡入期间以 16ms 定时重绘，到点即停；没有图在淡入时不会产生额外重绘。
- 只在「图第一次出现」时淡入；之后滚动、切换筛选都不会重复播放。
- 播放、暂停、导入等逻辑均未改动。

### 安装

- 安装包：`WallDesk-4.13.0-setup.exe`（安装到用户目录，无需管理员权限）
- 绿色版：`WallDesk-4.13.0-win64.zip`，解压即用；便携模式在 exe 同目录放空的 `portable.ini`。
