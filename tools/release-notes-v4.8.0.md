## WallDesk v4.8.0

这一版不铺新功能，专门修掉几处「用起来别扭」的地方——下载下来的图不再重复堆积，
文件名能认得出是哪张，界面也重新分了层。

### 修复

- **重复下载不再堆副本**：同一张图再下一次，会在落盘前按文件内容（SHA-256，先比文件
  大小预筛）查重，命中已有文件就直接复用，不再生成 `xxx_1.jpg` 这类副本。
  此前 `downloads/` 里 14 个文件只有 10 份唯一内容，**白占 14.2 MiB**。
  Bing 每日一图更进一步——按命名就能判断出「今天这张已经下过」，连请求都不发。
- **设置页「场景预设」补上保存入口**：该分组此前只有「应用」没有「保存」，
  想存一个预设必须跳回壁纸库页，与设计意图不符。

### 改进

- **下载文件改为可读命名**：Bing 图存成 `bing_2026-09-24_ElGolfo.jpg`（日期取图源
  自身的 `startdate`，不是本机日期），其它网址存成 `域名_原文件名.jpg`，
  路径里没有可用文件名时退回 `域名_短哈希`。此前一律是 `wall_<url哈希>.jpg`，
  截断之后完全认不出是什么。
- **壁纸库页工具条收拢**：原四行九个按钮收成一条操作行加一个「更多」溢出菜单
  （添加图片 / 添加视频 / 从网址下载 / Bing 今日一图 / 移除选中 / 清空库 /
  停止壁纸 / 重新挂载桌面层 / 预设存删），画廊多出一行可视面积。
- **设置页加二级导航**：12 个分组的单列长滚动改为左侧分类加右侧滚动区，
  分「壁纸 / 播放 / 场景 / 外观与效果 / 高级」五页，停在哪个子页会被记住。

### 兼容性与注意

- 配置、预设（`presets.json`）、播放历史、壁纸库清单的格式**均未变**，可直接覆盖安装。
- **已存在的重复下载文件不会被自动删除**——本版只保证今后不再新增。
  想清理旧副本，可手动删除 `downloads/` 目录里的 `*_1.jpg` / `*_2.jpg`。

### 安装说明

- `WallDesk-4.8.0-setup.exe` — 安装程序，装到 `%LOCALAPPDATA%\Programs\WallDesk`，无需管理员权限。
- `WallDesk-4.8.0-win64.zip` — 绿色版，解压即用。

视频引擎 libVLC 3.0.x 已内嵌，无需单独安装 VLC。
各文件校验值见包内 `SHA256SUMS.txt`。
