# WallDesk

[![版本](https://img.shields.io/badge/version-4.18.1-2563EB)](https://github.com/Gitsnod/WallDesk/releases/latest)
[![平台](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-0078D4)](#能装在哪台机器上)
[![许可](https://img.shields.io/badge/license-MIT-16A34A)](LICENSE)

把视频铺成 Windows 桌面壁纸。图标在它上面，照常点；桌面右键菜单也照常出。

图片壁纸、多屏独立、按时段自动换都能用。C++ + Qt 写的原生程序，不注入 explorer，
不挂钩子，不套浏览器内核。

**[⬇ 下载最新版](https://github.com/Gitsnod/WallDesk/releases/latest)**

## 下载哪个

| 文件 | 说明 |
|------|------|
| `WallDesk-x.y.z-setup.exe` | 装到用户目录，不要管理员权限。带桌面图标、开始菜单、可选开机自启和卸载 |
| `WallDesk-x.y.z-win64.zip` | 绿色版。解压就能跑，删目录就卸干净，包里附 `SHA256SUMS.txt` |

两个包都自带 Qt 和 VLC，不用另装依赖，体积约 57 MB。

### 能装在哪台机器上

- Windows 10 / 11，64 位
- 如果装了第三方桌面美化工具，它可能占住 `WorkerW` 图层。这时 WallDesk 会退回成置底窗口：
  壁纸照样动，但会盖住图标。重启一次 `explorer.exe` 通常能抢回来
- 4K 视频建议显卡支持硬解，否则 CPU 会一直在跑

## 第一次用

1. 点「更多 → 添加图片…／添加视频…」，或者直接把文件拖进窗口
2. 在画廊里选中一项，点「应用选中」，双击也行
3. 关掉窗口不等于退出，它还在托盘里跑。想开机就恢复上次的壁纸，
   去 设置 → 播放 → 自动化，勾上「开机自动启动」和「启动时恢复上次壁纸」
4. 托盘图标右键能换壁纸、暂停、退出

## 功能

### 壁纸

| 功能 | 说明 |
|------|------|
| 图片 | 六种填充：填充 / 适应 / 拉伸 / 平铺 / 居中 / 跨区（多屏） |
| 视频 | H.264 最稳。HEVC、AV1 看显卡支不支持硬解 |
| 多屏 | 左侧「多屏」页给每台显示器单独指定图片。视频还是只播一个实例，省内存 |
| 场景预设 | 壁纸 + 画面效果 + 挂件 + 切换策略打包成一个命名场景，存在 `presets.json` 里，可以直接编辑或拷走 |
| 定时场景 | 设置 → 场景，按时段自动换壁纸 |

### 桌面增强

| 功能 | 说明 |
|------|------|
| 画面效果 | 设置 → 外观与效果。亮度、对比度、饱和度、模糊、暗角、黑白，调的时候实时预览 |
| 桌面挂件 | 同上。时钟、日历、自定义文字，浮在壁纸上面 |
| 音乐可视化 | 同上。走 WASAPI 回环采集音频，桌面显示频谱条。视频音量调到 0 时不碰音频链路，最省电 |
| 主题 | 浅色 / 深色 / 跟随系统 |

### 省电与自动化

| 功能 | 默认 | 说明 |
|------|------|------|
| 锁屏暂停 | 开 | 锁屏就停，解锁续播 |
| 全屏应用暂停 | 开 | 检测到游戏或全屏视频时暂停 |
| 电池供电暂停 | 关 | 笔记本建议开 |
| 远程桌面暂停 | 开 | 远程连接时停掉，免得远端卡 |
| 空闲暂停 | 关 | 无键鼠输入到达设定分钟数（默认 5）就停，一动就续播 |
| 逐应用规则 | 关 | 指定某个程序在前台时暂停，或者反过来忽略全屏暂停（比如让 OBS 录屏时不停） |
| 自动切换 | 关 | 按间隔顺序或随机换，可以限定范围 |

暂停原因之间互不覆盖：全屏结束了，电池那条暂停还在。

### 壁纸库

- **搜索与筛选**：按文件名搜；按全部 / 图片 / 视频 / 收藏 / 在线下载过滤；按分辨率、朝向筛；按添加时间或分辨率排序
- **在线图源**：「更多 → 从网址下载…」可以一次贴多个网址；「更多 → Bing 今日一图」抓当天原图。
  同一张图重复下载不会堆副本，文件名是 `bing_2026-09-24_ElGolfo.jpg` 这种
- **缩略图**：小 / 中 / 大 / 自适应四档。窗口缩放只改列数，不改格子大小。
  视频缩略图默认开着，后台串行抓帧（同时只开一个解码实例），抓失败就退回占位图
- **悬停预览**：鼠标停在视频卡片上会动起来，设置 → 高级 里能关
- **收藏**：右键收藏，过滤条能只看收藏

## 命令行参数

| 参数 | 作用 |
|------|------|
| `--minimized` | 直接驻留托盘，不开窗口（开机自启用的就是它） |
| `--next` | 通知正在运行的实例切到下一张 |
| `--quit` | 通知正在运行的实例退出 |
| `--portable` | 这次强制用便携模式 |
| `--verbose` | 日志里记调试信息 |

重复启动不会开第二个窗口，新进程把命令转给已在运行的实例后自己退出。
所以「下一张」可以做成桌面快捷方式，也可以挂到 AutoHotkey 热键上。

## 数据存在哪

| 东西 | 位置 |
|------|------|
| 配置与数据（安装版） | `%LOCALAPPDATA%\WallDesk` |
| 配置与数据（便携版） | 程序目录下的 `data` |
| 日志 | 数据目录下的 `logs\WallDesk.log`，超过 2 MB 自动滚动 |
| 下载的在线图片 | 数据目录下的 `downloads\` |

便携模式：设置 → 高级 → 其它 里勾选，或者在 exe 同目录放一个空的 `portable.ini`。
开了以后不写注册表，整个文件夹拷到 U 盘就能带走。

## 出问题的时候

| 现象 | 怎么办 |
|------|--------|
| 提示「未能加载 libvlc.dll」 | 绿色版缺文件，或者自己编译时没打包 VLC。重新下完整包，或者界面上「定位 libvlc」手动指 |
| 提示「未能定位桌面 WorkerW 图层」 | 见上面「能装在哪台机器上」。重启 `explorer.exe` 再试 |
| 视频黑屏，但显示「已应用」 | 编码不支持。设置 → 播放 → 解码档位 换一档，或者换成 H.264 |
| 休眠唤醒后视频没了 | 程序会监听电源广播自动重挂，另有看门狗兜底。还不行就在日志里搜 `视频宿主窗口` |
| 资源管理器重启后失效 | 看门狗每 2–8 秒校验一次，异常会自动重挂 |
| 双击没反应 | 它是单实例的，可能已经在托盘里。点托盘图标，或者再启动一次唤醒窗口 |
| 笔记本掉电变快 | 视频壁纸本身就费电。确认「锁屏暂停」「全屏暂停」开着，电池场景可以再开「电池暂停」 |
| 想彻底删掉 | 安装版走系统「应用和功能」。绿色版删目录，再顺手清掉 `%LOCALAPPDATA%\WallDesk` |

没列出来的问题，带上 `logs\WallDesk.log` 提到 [Issues](https://github.com/Gitsnod/WallDesk/issues)。
日志第一行就有系统和 Qt 版本。
